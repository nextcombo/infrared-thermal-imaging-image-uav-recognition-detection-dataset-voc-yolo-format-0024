# Infrared Thermal Imaging Image UAV Recognition Detection Dataset VOC+YOLO format 10000 images in 1 category

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 10000

Number of annotations (number of xml files): 10000

Number of annotations (number of txt files): 10000

Label category count: 1

Label category name: ["drone"]

Number of boxes and the number of images occupied by each category:

Drone frame count = 10000, occupying image count = 10000

Total frame count: 10000

Image resolution: 640x512

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: The dataset does not have separate training, validation, and test sets; you need to partition them yourself.

Special : This dataset does not guarantee the accuracy of the trained models or weight files.
